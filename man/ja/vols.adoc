== NAME

vols - bas-cpp が検出したローカルボリュームを一覧表示する

== SYNOPSIS

*vols* [_オプション_]

== DESCRIPTION

*vols* は bas-cpp のボリュームサブシステムが認識するローカルボリュームを列挙し、見出し行のあと各ボリュームを 1 行ずつ出力します。列はタブ区切りです。

フィールド選択オプション（*-a*、*-c*、*-m*、*-d*、*-t*、*-l*、*-u*、*-r*、*-L*、*-D*、*-o*、*-O*、*-z*）を何も指定しない場合、既定の列は *-mdtlu*（マウントポイント、デバイス、タイプ、ラベル、UUID）です。*-v* / *--verbose* では既定列は *-mdtlurLD*（上記 5 つに加えて読み取り専用、論理タイプ、ループデバイス）です。*-c / --compact* はコンパクト列セット（*-mdtlu*）のみを選びます（*-v* 併用時も同様）。*-a / --all* はすべての列を選びます（すべてのフィールドフラグを組み合わせるのと同じ）。

バインドマウントは常にスキャンに含まれます。オーバーレイファイルシステムは *-s* / *--symbols* を渡したとき、または論理タイプ列が選ばれたとき（*-L* / *--logical-type*、あるいは *-v* の既定）に追加されます。

*-w / --writable* は書き込み可能なマウントだけを一覧し、読み取り専用列（*-r*）を暗示するため、各行は依然として *ro* / *rw* を示します。

== OPTIONS

=== フィールド列

*-a*, *--all*::
  利用可能なすべての列を表示します。
*-c*, *--compact*::
  コンパクト列セット（*-mdtlu*）を使います。明示的なフィールドフラグがある場合、compact はそれらの列と OR 結合されます。
*-m*, *--mountpoint*::
  マウントポイント（またはルートパス）。
*-d*, *--device*::
  デバイスパス（または -）。
*-t*, *--type*::
  ボリュームタイプ。
*-l*, *--label*::
  ラベル。
*-u*, *--uuid*::
  UUID。
*-r*, *--read-only*::
  読み取り専用フラグ（*ro* / *rw*）。
*-L*, *--logical-type*::
  論理マウント種別（*-*、*bind*、*overlay*）。
*-D*, *--loop-device*::
  ループデバイスマーカー（*loop* / *-*）。
*-o*, *--opts*::
  */proc/self/mountinfo* からのマウント単位（VFS）オプション文字列。
*-O*, *--superopts*::
  */proc/self/mountinfo* からのスーパーブロックオプション文字列。
*-z*, *--root*::
  ファイルシステム内のルートパス（mountinfo の「root」フィールド。マウントポイントの前）。

=== その他

*-s*, *--symbols*::
  ボリュームスキャンにオーバーレイファイルシステムを含めます（バインドマウントは常に含まれます）。
*-h*, *--help*::
  使い方を表示して正常終了します。
*-w*, *--writable*::
  読み取り専用ボリュームを省略します。*-r* を暗示します。
*-v*, *--verbose*::
  ライブラリのログしきい値を下げます（stderr により多くのメッセージ）。フィールドフラグがない場合、詳細モードの既定列セットを選びます。
*-q*, *--quiet*::
  stderr 上のライブラリ警告を抑制します（エラーのみ）。

*-v* と *-q* は同時に使えません。*-a* と *-c* も同時に使えません。

== EXIT STATUS

成功時は 0、無効なオプション・競合するフラグ・予期しない引数では 2 で終了します。
