== NAME

vols - سرد وحدات التخزين المحلية التي يكتشفها bas-cpp

== SYNOPSIS

*vols* [_خيارات_]

== DESCRIPTION

*vols* يعدّد وحدات التخزين المحلية المعروفة لنظام فرعي وحدات التخزين في bas-cpp ويطبع صف رأس ثم سطراً لكل وحدة. الأعمدة مفصولة بعلامات جدولة.

إذا لم تمرّر أي خيار لاختيار الحقول (*-a*، *-c*، *-m*، *-d*، *-t*، *-l*، *-u*، *-r*، *-L*، *-D*، *-o*، *-O*، *-z*)، فالأعمدة الافتراضية هي *-mdtlu* (نقطة التركيب، الجهاز، النوع، التسمية، UUID). مع *-v* / *--verbose* تكون الأعمدة الافتراضية *-mdtlurLD* (تلك الخمسة إضافةً إلى القراءة فقط، النوع المنطقي، جهاز الحلقة). *-c / --compact* يختار فقط مجموعة الأعمدة المدمجة (*-mdtlu*)، حتى مع *-v*. *-a / --all* يختار كل الأعمدة (مثل جمع كل أعلام الحقول).

تركيبات bind تُدرج دائماً في الفحص. تُضاف أنظمة ملفات overlay عند تمرير *-s* / *--symbols*، أو عند اختيار عمود النوع المنطقي (*-L* / *--logical-type*، أو افتراضيات *-v*).

*-w / --writable* يسرد التركيبات القابلة للكتابة فقط ويتضمن عمود القراءة فقط (*-r*) بحيث يظهر كل صف مطبوع لا يزال *ro* / *rw*.

== OPTIONS

=== أعمدة الحقول

*-a*, *--all*::
  طباعة كل الأعمدة المتاحة.
*-c*, *--compact*::
  استخدام مجموعة الأعمدة المدمجة (*-mdtlu*)؛ مع أعلام حقول صريحة تُدمج compact مع تلك الأعمدة (OR).
*-m*, *--mountpoint*::
  نقطة التركيب (أو مسار الجذر).
*-d*, *--device*::
  مسار الجهاز (أو -).
*-t*, *--type*::
  نوع وحدة التخزين.
*-l*, *--label*::
  التسمية.
*-u*, *--uuid*::
  UUID.
*-r*, *--read-only*::
  علم القراءة فقط (*ro* / *rw*).
*-L*, *--logical-type*::
  نوع التركيب المنطقي (*-*، *bind*، *overlay*).
*-D*, *--loop-device*::
  علامة جهاز الحلقة (*loop* / *-* ).
*-o*, *--opts*::
  سلسلة خيارات لكل تركيب (VFS) من */proc/self/mountinfo*.
*-O*, *--superopts*::
  سلسلة خيارات الكتلة الفائقة من */proc/self/mountinfo*.
*-z*, *--root*::
  مسار الجذر داخل نظام الملفات (حقل «root» في mountinfo، قبل نقطة التركيب).

=== أخرى

*-s*, *--symbols*::
  تضمين أنظمة ملفات overlay في فحص الوحدات (تركيبات bind تُدرج دائماً).
*-h*, *--help*::
  طباعة الاستخدام والخروج بنجاح.
*-w*, *--writable*::
  حذف وحدات القراءة فقط؛ يتضمن *-r*.
*-v*, *--verbose*::
  خفض عتبة سجل المكتبة (مزيد من الرسائل على stderr). بلا أعلام حقول، يختار مجموعة الأعمدة الافتراضية المفصّلة.
*-q*, *--quiet*::
  كبح تحذيرات المكتبة على stderr (الأخطاء فقط).

لا يمكن استخدام *-v* و*-q* معاً. لا يمكن استخدام *-a* و*-c* معاً.

== EXIT STATUS

يخرج بـ 0 عند النجاح، و2 للخيارات غير الصالحة أو الأعلام المتعارضة أو الوسائط غير المتوقعة.
