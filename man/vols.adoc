== NAME

vols - list local volumes detected by bas-cpp

== SYNOPSIS

*vols* [_options_]

== DESCRIPTION

*vols* enumerates local volumes known to the bas-cpp volume subsystem and prints one header row plus one line per volume. Columns are tab-separated.

If you do not pass any field-selection option (*-a*, *-c*, *-m*, *-d*, *-t*, *-l*, *-u*, *-r*, *-L*, *-D*, *-o*, *-O*, *-z*), the default columns are *-mdtlu* (mount point, device, type, label, UUID). With *-v* / *--verbose*, the default columns are *-mdtlurLD* (those five plus read-only, logical type, loop device). *-c / --compact* selects only the compact column set (*-mdtlu*), even with *-v*. *-a / --all* selects every column (same as combining all field flags).

Bind mounts are always included in the scan. Overlay filesystems are added when you pass *-s* / *--symbols*, or when the logical-type column is selected (*-L* / *--logical-type*, or *-v* defaults).

*-w / --writable* lists only writable mounts and implies the read-only column (*-r*) so each printed row still shows *ro* / *rw*.

== OPTIONS

=== Field columns

*-a*, *--all*::
  Print every available column.
*-c*, *--compact*::
  Use the compact column set (*-mdtlu*); with explicit field flags, compact is ORed with those columns.
*-m*, *--mountpoint*::
  Mount point (or root path).
*-d*, *--device*::
  Device path (or -).
*-t*, *--type*::
  Volume type.
*-l*, *--label*::
  Label.
*-u*, *--uuid*::
  UUID.
*-r*, *--read-only*::
  Read-only flag (*ro* / *rw*).
*-L*, *--logical-type*::
  Logical mount kind (*-*, *bind*, *overlay*).
*-D*, *--loop-device*::
  Loop device marker (*loop* / *-*).
*-o*, *--opts*::
  Per-mount (VFS) option string from */proc/self/mountinfo*.
*-O*, *--superopts*::
  Superblock option string from */proc/self/mountinfo*.
*-z*, *--root*::
  Root path within the filesystem (mountinfo “root” field, before the mount point).

=== Other

*-s*, *--symbols*::
  Include overlay filesystems in the volume scan (bind mounts are always included).
*-h*, *--help*::
  Print usage and exit successfully.
*-w*, *--writable*::
  Omit read-only volumes; implies *-r*.
*-v*, *--verbose*::
  Lower the library log threshold (more messages on stderr). With no field flags, selects the verbose default column set.
*-q*, *--quiet*::
  Suppress library warnings on stderr (errors only).

*-v* and *-q* cannot be used together. *-a* and *-c* cannot be used together.

== EXIT STATUS

Exits 0 on success, 2 for invalid options, conflicting flags, or unexpected arguments.
