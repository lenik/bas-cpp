== NAME

vols - bas-cpp가 감지한 로컬 볼륨 나열

== SYNOPSIS

*vols* [_옵션_]

== DESCRIPTION

*vols*는 bas-cpp 볼륨 하위 시스템이 아는 로컬 볼륨을 열거하고 머리글 한 행과 볼륨당 한 줄을 출력합니다. 열은 탭으로 구분됩니다.

필드 선택 옵션(*-a*, *-c*, *-m*, *-d*, *-t*, *-l*, *-u*, *-r*, *-L*, *-D*, *-o*, *-O*, *-z*)을 하나도 주지 않으면 기본 열은 *-mdtlu*(마운트 지점, 장치, 형식, 레이블, UUID)입니다. *-v* / *--verbose*에서는 기본 열이 *-mdtlurLD*(위 다섯에 읽기 전용, 논리 형식, 루프 장치 추가)입니다. *-c / --compact*는 컴팩트 열 집합(*-mdtlu*)만 선택합니다(*-v*와 함께여도). *-a / --all*은 모든 열을 선택합니다(모든 필드 플래그를 합친 것과 같음).

바인드 마운트는 항상 스캔에 포함됩니다. 오버레이 파일시스템은 *-s* / *--symbols*를 주거나 논리 형식 열이 선택된 경우(*-L* / *--logical-type*, 또는 *-v* 기본값)에 추가됩니다.

*-w / --writable*는 쓰기 가능한 마운트만 나열하며 읽기 전용 열(*-r*)을 암시하여 각 출력 행이 여전히 *ro* / *rw*를 보이게 합니다.

== OPTIONS

=== 필드 열

*-a*, *--all*::
  사용 가능한 모든 열을 출력합니다.
*-c*, *--compact*::
  컴팩트 열 집합(*-mdtlu*)을 사용합니다. 명시적 필드 플래그가 있으면 compact가 해당 열과 OR 병합됩니다.
*-m*, *--mountpoint*::
  마운트 지점(또는 루트 경로).
*-d*, *--device*::
  장치 경로(또는 -).
*-t*, *--type*::
  볼륨 형식.
*-l*, *--label*::
  레이블.
*-u*, *--uuid*::
  UUID.
*-r*, *--read-only*::
  읽기 전용 플래그(*ro* / *rw*).
*-L*, *--logical-type*::
  논리 마운트 종류(*-*, *bind*, *overlay*).
*-D*, *--loop-device*::
  루프 장치 표시(*loop* / *-*).
*-o*, *--opts*::
  */proc/self/mountinfo*의 마운트별(VFS) 옵션 문자열.
*-O*, *--superopts*::
  */proc/self/mountinfo*의 슈퍼블록 옵션 문자열.
*-z*, *--root*::
  파일시스템 내 루트 경로(마운트 지점 앞의 mountinfo “root” 필드).

=== 기타

*-s*, *--symbols*::
  볼륨 스캔에 오버레이 파일시스템을 포함합니다(바인드 마운트는 항상 포함).
*-h*, *--help*::
  사용법을 출력하고 성공적으로 종료합니다.
*-w*, *--writable*::
  읽기 전용 볼륨을 생략합니다. *-r*을 암시합니다.
*-v*, *--verbose*::
  라이브러리 로그 임계값을 낮춥니다(stderr에 메시지 증가). 필드 플래그가 없으면 자세한 기본 열 집합을 선택합니다.
*-q*, *--quiet*::
  stderr의 라이브러리 경고를 억제합니다(오류만).

*-v*와 *-q*는 함께 쓸 수 없습니다. *-a*와 *-c*도 함께 쓸 수 없습니다.

== EXIT STATUS

성공 시 0, 잘못된 옵션·충돌하는 플래그·예상치 못한 인자 시 2로 종료합니다.
